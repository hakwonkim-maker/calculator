# MEMORIA 기념영상 스튜디오

사진 폴더만 선택하면 **인트로 → 사진(자연스러운 전환·카메라 움직임·자막) → 엔딩**으로 이어지는
행사용 기념 영상(MP4)을 만들어 주는 PC 설치형 프로그램입니다. 30주년 같은 기념식 상영을 목표로 설계했습니다.

---

## 1. 빠른 시작

### 설치 파일 받기 (권장)
GitHub → **Actions → "MEMORIA Windows Installer"** → 최신 실행의 Artifacts에서
`MEMORIA-Film-Studio-Setup-x.y.z.exe` 다운로드 → 설치.

### 직접 빌드
```bash
cd memory-film
npm install
npm run start        # 앱 실행 (빌드 후 Electron 실행)
npm run dist:win     # Windows 설치 파일 → release/*.exe  (Windows에서 실행)
npm run dist:mac     # macOS dmg (Mac에서 실행)
```
개발 모드: 터미널 1 `npm run dev`, 터미널 2 `npm run electron:dev` (수정 즉시 반영).

### 사용 흐름 (5단계)
| 단계 | 하는 일 |
|---|---|
| ① 사진 | 폴더 선택(하위 폴더 포함) → 촬영일순 자동 정렬. 연도별 챕터 카드·연도 라벨 자동 생성 |
| ② 문구 | 인트로 스타일 선택, "30 / ANNIVERSARY / 함께 걸어온 30년 / 1996—2026 / 회사명", 로고, 엔딩 감사 문구 |
| ③ 스타일 | 컬러 테마 4종, 타이포그래피 4종, 전환 스타일(우아/시네마틱/경쾌), 카메라 움직임, 사진 색감 |
| ④ 음악 | 여러 곡 크로스페이드, 반복, 페이드인/아웃, **음악 길이에 영상 자동 맞추기** |
| ⑤ 내보내기 | 점검 체크리스트 → 1080p/4K, 30/60fps → MP4 생성 |

단축키: `Space` 재생 · `←/→` 장면 이동 · `Delete` 삭제 · `Ctrl+Z / Ctrl+Shift+Z` 실행취소/재실행 · `Ctrl+S` 저장 · `Ctrl+A` 전체 선택

## 2. 영상 디자인

### 인트로 3종
| 스타일 | 연출 |
|---|---|
| **골든 타이틀** | 빛줄기·보케 입자 속에서 금박 숫자 "30"이 블러에서 선명해지며 등장 → 광택 스윕 → ANNIVERSARY 자간이 좁혀지며 양옆 라인이 그려짐 → 한글 타이틀이 한 글자씩 떠오름 → 연도·회사명·로고 |
| **메모리 모자이크** | 우리 사진들이 기울어진 벽처럼 중앙부터 퍼지며 나타남 → 피사계심도처럼 흐려지고 어두워짐 → 타이틀 |
| **이어온 시간** | 창립 연도 → 올해까지 기계식 카운터처럼 숫자가 굴러감(1996→2026) + 진행 라인 → 타이틀 |

인트로 길이를 바꾸면 애니메이션 타이밍이 비례해서 늘거나 줄어듭니다.

### 사진 장면
- **켄 번스 모션**: 확대/축소/좌우/상하 패닝을 시드 기반으로 섞되 같은 움직임이 연속되지 않게 배치. 인물 얼굴이 주로 있는 화면 위쪽으로 살짝 치우친 구도.
- **화면 맞춤(자동)**: 16:9·3:2 사진은 꽉 채우고, 4:3·세로·정사각 사진은 잘리지 않도록 **같은 사진의 흐린 배경 + 그림자 있는 원본**으로 표시 (단체사진 머리 잘림 방지). 옵션: 인화지 흰 테두리.
- **자막**: 금색 연도 라벨 + 설명 문구가 글자 단위로 등장, 하단 그라데이션으로 가독성 확보.
- **챕터 카드**: "1996 · 작은 시작" 같은 구간 제목. 다음 사진을 흐리게 깐 배경 위에 표시.
- **엔딩**: 사진 갤러리 월이 천천히 흐르는 위로 감사 메시지 → 회사명/로고 → 블랙 페이드아웃(진행자가 정지할 여유).

### 전환 효과 14종 (WebGL 셰이더)
디졸브 · 블러 디졸브 · 빛 번짐 · 라이트 릭 · 모프 · 소프트 와이프 · 아이리스 · 블랙 페이드 · 화이트 플래시 · 줌 블러 · 패럴랙스 슬라이드 · 크로스 워프 · 물결 · 소용돌이
— 스타일별 가중치로 자동 선택(같은 효과 연속 방지), 필름스트립의 ◆ 버튼으로 개별 지정 가능.
전환 중에도 두 장면의 움직임이 계속되어 "멈춘 사진이 바뀌는" 느낌이 없습니다.

### 타이포그래피 (모두 SIL OFL, 앱에 내장 → 인터넷 없는 행사장에서도 동일)
| 프리셋 | 숫자/영문 | 한글 |
|---|---|---|
| 클래식 명조 | Bodoni Moda | Noto Serif KR (본명조) |
| 모던 고딕 | Pretendard (Thin) | Pretendard |
| 로열 클래식 | Cinzel | 나눔명조 |
| 감성 바탕 | Gilda Display | 고운바탕 |

숫자용 폰트는 직접 렌더 비교 후 **라이닝 숫자**(기준선 정렬) 폰트만 채택했습니다. Cormorant·Playfair는 올드스타일 숫자라 "3"이 아래로 처져 제외.

### 색보정 · 마감
사진 색감 5종(자연/따뜻한 필름/빈티지/선명/흑백)은 **사진에만** 적용되어 금색 타이틀은 변색되지 않습니다.
비네팅·필름 그레인, 그리고 어두운 그라데이션의 **색 띠(밴딩) 방지 디더링**을 최종 단계에서 적용합니다.

## 3. 아키텍처

```
┌──────────────────────── Electron Main (Node) ────────────────────────┐
│ main.cjs   창 · 파일/폴더 대화상자 · 사진 스캔(EXIF 촬영일) · media:// 프로토콜 │
│ exporter.cjs  FFmpeg 프로세스: RGBA 프레임(stdin) + 음악 필터그래프 → MP4      │
└───────────────▲──────────────── IPC (preload.cjs, contextIsolation) ─┘
                │ 프레임 버퍼 / 진행 상태
┌───────────────┴──────────────── Renderer (React) ────────────────────┐
│ UI: App · Panels · Preview · Filmstrip · Inspector · ExportModal       │
│                                                                       │
│ Engine (UI와 독립, 미리보기·출력 공용)                                    │
│  timeline.js  프로젝트 → 겹치는 세그먼트 + 전환/모션 결정(시드 기반)         │
│  scenes.js    Canvas2D 장면: 인트로 3종 · 사진 · 챕터 · 엔딩               │
│  compositor   WebGL2: 장면 A/B → 전환 셰이더 → 룩/비네팅/그레인/디더        │
│  assets.js    해상도 맞춤 디코딩 + 블러 배경 + LRU 캐시                     │
│  audio.js     미리보기 음악 (FFmpeg와 동일한 크로스페이드/페이드 규칙)       │
└───────────────────────────────────────────────────────────────────────┘
```

**핵심 설계 원칙**
1. **결정적 렌더링** — 모든 프레임은 `시간 t`의 순수 함수(랜덤도 시드 기반). 그래서 미리보기와 최종 영상이 프레임 단위로 같고, 어느 지점이든 즉시 탐색 가능.
2. **해상도 독립 디자인** — 1080p 기준 단위(`u = H/1080`)로 디자인 → 720p 미리보기, 4K 출력 모두 같은 레이아웃.
3. **메모리 안전** — 2천만 화소 원본을 그대로 쓰지 않고 출력 해상도×1.35로 줄여 보관, 최근 장면만 캐시. 사진 수백 장도 안정적.
4. **표준 출력** — H.264 High / yuv420p / BT.709 / faststart MP4 + AAC 256k. 행사장 PC, PowerPoint, 프로젝터 플레이어 어디서나 재생.

### 프로젝트 파일
`.memoria` (JSON). 사진은 원본 경로를 참조합니다. 사진 폴더를 옮기면 "파일 없음"으로 표시됩니다.
작업 내용은 자동 저장되어 프로그램이 갑자기 꺼져도 다음 실행 시 복원됩니다.

## 4. 실사용자 관점 검토 → 반영 사항

| 실제 상황 | 대응 |
|---|---|
| 세로/옛날 4:3 사진이 섞임, 단체사진 머리가 잘림 | 자동 맞춤 + 흐린 배경, 사진별·일괄 변경 |
| 오래된 스캔 사진은 해상도가 낮음 | 장변 1500px 미만 **저해상도 배지** + 점검 목록에서 클릭 시 해당 사진 선택 |
| 30년 역사를 시대순으로 | 촬영일 정렬, 연도별 챕터 자동 생성, 연도 라벨 자동 입력 (EXIF 없는 스캔본은 파일 날짜로 구분 표시) |
| 음악 끝과 영상 끝이 안 맞음 | "음악 길이에 영상 맞추기" (사진 1장당 시간 역산), 너무 짧/길면 경고 |
| 아이폰 HEIC 사진 | 가져올 때 제외하고 개수·변환 방법 안내 |
| 행사장 인터넷 없음 | 폰트·FFmpeg 모두 내장, 완전 오프라인 동작 |
| 실수로 삭제/수정 | 실행 취소 80단계, 삭제 토스트의 "되돌리기" |
| 며칠에 걸쳐 작업 | 프로젝트 저장/열기 + 자동 저장·복원 |
| 내보내기 중 절전/화면 꺼짐 | 절전 차단, 최소화해도 계속 진행, 진행 중 종료 시 확인 |
| GPU 드라이버 없는 사무용 PC/가상머신 | SwiftShader 소프트웨어 렌더링 폴백 (느리지만 동작) |
| 영상 끝에서 진행자가 정지 | 엔딩 블랙 페이드아웃 후 검은 화면 유지 |
| 화면 가장자리가 잘리는 프로젝터 | 모든 글자를 화면 90% 안전 영역 안에 배치, 긴 문구는 자동 축소 |

## 5. 테스트

```bash
npm run fixtures                         # 다양한 비율의 샘플 사진·음악 생성 (ffmpeg 필요)
PW_PATH=<playwright 경로> npm run test:render -- golden   # 지정 시간 프레임을 tests/out 에 이미지로 저장 (golden|mosaic|light|royal)
PW_PATH=<playwright 경로> npm run test:ui                 # UI 각 단계 스크린샷
PW_PATH=<playwright 경로> xvfb-run -a npm run test:e2e    # 실제 Electron 앱: 폴더 가져오기→자막→음악→720p 내보내기
```
E2E는 개발 실행과 패키징된 앱(`MF_EXE=release/linux-unpacked/memoria-film-studio`) 모두에서 통과했으며,
결과 MP4(H.264 yuv420p BT.709 30fps + AAC)를 ffprobe와 프레임 추출로 검증했습니다.

## 6. 알려진 제약 / 다음 단계 후보
- HEIC·RAW 직접 지원 없음 (JPG 변환 필요)
- 얼굴 인식 기반 자동 구도는 미적용 (상단 치우침 구도로 대응)
- 코드 서명이 없어 Windows SmartScreen 경고가 뜰 수 있음 → "추가 정보 → 실행"
- 후보: 사진별 개별 카메라 움직임 지정, 동영상 클립 삽입, 하드웨어 인코더(NVENC/QSV) 가속
