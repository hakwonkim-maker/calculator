# MEMORIA 기념영상 스튜디오 — 사용 설명서

모든 기능은 **마우스 클릭**으로 적용됩니다. 무엇을 누르든 가운데 미리보기에 바로 반영되니 마음껏 눌러 보세요.
실수해도 **Ctrl+Z**(또는 상단 ↶ 버튼)로 되돌릴 수 있고, 작업은 자동 저장됩니다.

```
┌ 상단: 템플릿 · 새로 만들기 · 열기 · 저장 · [영상 만들기] ─────────────────┐
│ 단계 │ 설정 패널     │        미리보기 (재생·탐색)       │ 선택 항목 속성 │
│ 사진 │ (단계별 옵션) │                                   │ (자막·회전 등) │
│ 문구 │               │                                   │                │
│스타일│               ├───────────────────────────────────┴────────────────┤
│ 음악 │               │ 필름스트립: 인트로 ◆ 사진 ◆ 사진 ◆ … ◆ 엔딩         │
│내보내기               │ (드래그로 순서 변경, ◆ 클릭 = 전환 효과 선택)        │
└──────┴───────────────┴────────────────────────────────────────────────────┘
```

## 빠른 시작 (5분)
1. 프로그램을 켜면 **"어떤 영상을 만드시나요?"** 창이 뜹니다 → 원하는 종류를 클릭
   (창립·기념일 / 웨딩 / 생일·돌잔치 / 졸업·입학 / 여행 앨범 / 가족 앨범 / 추모·헌정 / 행사 하이라이트 / 연말 결산)
2. **사진 폴더 선택** → 사진이 촬영일 순서로 들어옵니다
3. 왼쪽 **문구** 단계에서 제목·날짜·이름을 내 내용으로 바꿉니다
   - 폴더 안의 사진을 프로그램이 알아서 배치합니다: 한 장씩 크게 보여 주다가 사이사이에 **몽타주 장면**(여러 장이 한 화면에)이 자동으로 섞입니다
4. **음악** 단계 → **무료 음악 고르기**에서 ▶로 들어 보고 **넣기**
5. **사진** 단계의 **영상 길이**에서 *전체 길이 정하기* → 예: *3분* 클릭 (또는 **음악** 단계 → *음악 길이에 영상 맞추기*)
6. **내보내기** → *영상 파일 만들기* → 저장 위치 선택 → 완료되면 *영상 재생*

## 1단계 · 사진
| 기능 | 사용법 |
|---|---|
| 사진 불러오기 | **폴더 선택**(하위 폴더 포함 가능) 또는 **사진 선택**. 사진·폴더를 창에 끌어다 놓아도 됩니다 |
| 순서 정리 | **촬영일순 / 파일명순 / 역순 / 섞기** 버튼. 촬영일은 ① 사진의 촬영 정보(EXIF) ② 파일 이름의 날짜(예: `KakaoTalk_19990512…`, `1999-05-12 졸업.jpg`) ③ 폴더 이름의 연도(예: `1999_창립식`, `2019년 송년회`) 순서로 판단합니다. 필름스트립에서 사진을 끌어 원하는 위치에 놓기 |
| 여러 장 선택 | Shift+클릭(범위), Ctrl+클릭(하나씩), Ctrl+A(전체) → 함께 끌어 옮기거나 삭제 |
| 연도별 챕터 자동 생성 | 촬영 연도가 바뀌는 곳마다 "1998" 같은 제목 카드를 자동 삽입 (폴더·파일 이름의 연도도 사용) |
| 사진에 촬영 연도 표시 | 각 사진 자막에 촬영 연도를 자동 입력 |
| 챕터(텍스트) 카드 추가 | 사진 사이에 "1부 · 우리의 시작" 같은 제목 화면 넣기 |
| **영상 길이** | ① **전체 길이 정하기**: 분·초를 입력하거나 1·2·3·5·10·15분 / ♪음악 길이 클릭 → 사진 1장당 시간이 자동 계산되고, 사진을 더 넣어도 전체 길이는 그대로 유지<br>② **사진 1장당 시간 정하기**: 1~12초 슬라이더 (사진 수에 따라 전체 길이가 늘어남) |
| 화면 맞춤 | 자동(권장) / 꽉 채우기 / 전체 보이기(흐린 배경) |

### 자동 사진 선별 (사진이 많을 때 좋은 사진만)
폴더째 불러오면 사진이 모두 들어갑니다. 영상이 너무 길어지면 프로그램이 좋은 사진만 골라 줍니다.
1. 사진을 불러온 뒤 뜨는 안내의 **3분 영상으로 좋은 사진만 고르기**를 누르면 끝 (클릭 1번)
2. 직접 정하려면: **영상 길이 → 전체 길이 정하기** → 길이(예: 3분) → **자동 사진 선별**에서 *사진 1장당 보여 줄 시간*(2·3·4·5초) → **자동 선별 적용**
- 고르는 기준: ★대표·자막 사진은 항상 포함 → 연속 촬영(연사) 중복은 가장 좋은 1장 → 폴더(행사·연도)별로 고르게(옛날 사진 폴더가 밀려나지 않게) → 한 행사 안에서도 처음·중간·끝 고르게 → 흔들리거나 어둡거나 하얗게 날아간 사진은 뒤로
- 빠진 사진은 **지워지지 않고** 필름스트립에 흐리게 ‘제외’로 남습니다. 사진을 눌러 속성 창의 **영상에 사용**을 켜면 다시 들어갑니다 (여러 장 선택 후 *다시 넣기*도 가능)
- **모든 사진 사용**으로 언제든 선별을 해제할 수 있고, 적용 직후 알림의 **되돌리기**로도 취소됩니다
- 처음 선별할 때 사진 화질을 한 번 분석합니다 (사진 200장 기준 수 초~수십 초)

### 옛날 사진(스캔·메신저로 받은 사진)의 순서가 어긋날 때
스캔한 필름 사진이나 카카오톡 등으로 받은 사진에는 촬영일 정보가 없어, 파일 날짜(스캔·복사한 날)로 계산되면 1999년 사진이 2003년 사진보다 뒤에 나올 수 있습니다.
- **폴더 이름에 연도를 넣어 주세요** — 예: `1999_창립식`, `2003 야유회`. 그 폴더의 사진은 해당 연도로 정렬됩니다 (앞의 `01_` 같은 번호는 상관없음)
- 스캐너가 스캔한 날을 촬영일로 기록한 경우에도 폴더·파일 이름의 연도를 우선합니다
- 사진 단계에 *촬영일 정보가 없는 사진 N장* 안내가 뜨면 **해당 사진 보기**로 확인하고, 필요하면 필름스트립에서 끌어 옮기세요
- 속성 창에서 날짜 옆에 *(폴더 이름의 연도)*, *(파일 이름의 날짜)*, *(파일 날짜 · 촬영일 정보 없음)* 처럼 어디서 가져온 날짜인지 표시됩니다
- 이전 버전에서 만든 프로젝트도 **촬영일순**을 한 번 누르면 새 규칙으로 날짜를 다시 계산해 정렬합니다

### 사진이 많을 때 (200장 이상)
- 수백 장도 한 번에 불러올 수 있습니다 (360장으로 시험). 필름스트립은 화면에 보이는 사진부터 미리보기를 만듭니다.
- **전체 길이 정하기**를 쓰면 사진 수와 관계없이 원하는 길이로 맞춰집니다. 예: 300장을 5분에 → 1장당 약 0.9초 (빠른 슬라이드)
- 감상용이라면 1장당 **2초 이상**을 권장합니다 (200장 ≈ 8분, 300장 ≈ 12분). 1.5초보다 빠르면 점검 목록에 안내가 뜹니다.
- 전환 효과는 사진이 짧아지면 자동으로 짧아져 화면이 겹쳐 보이지 않습니다.
- 사진이 너무 많아 원하는 길이를 맞출 수 없으면, 가능한 최소 길이를 알려 줍니다.

## 몽타주 장면 (자동)
사진이 계속 한 장씩만 나오면 지루해지므로, 사진 7~10장마다 한 번씩 여러 장이 한 화면에 나오는 장면을 자동으로 넣습니다.
| 몽타주 | 모습 |
|---|---|
| 모자이크 그리드 | 4~6장이 차례로 채워지는 격자 |
| 폴라로이드 | 인화 사진이 테이블 위에 한 장씩 떨어지며 쌓임 |
| 분할 패널 | 화면이 3칸으로 나뉘어 사진이 번갈아 밀려 들어옴 |
| 필름 스트립 | 옛 필름이 비스듬히 흘러가며 사진이 지나감 |
- 필름스트립에서 몽타주에 들어간 사진은 하늘색 **‘폴라로이드’** 같은 표시와 연결선으로 보입니다
- 나오는 빈도: **스타일** 단계 → *몽타주 장면* → 끄기 / 가끔 / 보통 / 자주
- 특정 사진은 항상 크게 보이게 하려면: 사진 클릭 → 속성 창의 **몽타주에 넣어도 됨** 끄기 (자막을 넣은 사진도 자동으로 한 장씩 나옵니다)
- 몽타주 사진을 키보드 ←/→로 이동하면 몽타주 전체가 선택되고, 속성 창의 **몽타주 풀기**로 한 번에 한 장씩 보이게 바꿀 수 있습니다

## 사진 하나 다듬기 (오른쪽 속성 창)
필름스트립에서 사진을 클릭하면 오른쪽에 속성 창이 열립니다.
- **★ 대표 사진**: 인트로·엔딩의 사진 장면에 이 사진을 먼저 씁니다 (여러 장 선택 후 한 번에 지정 가능)
- **몽타주에 넣어도 됨**: 끄면 이 사진은 항상 한 장씩 크게
- **중심점**: 사진에서 꼭 보여야 할 곳(얼굴)을 클릭 → 화면을 꽉 채울 때 그 부분이 잘리지 않습니다
- **회전**: 옆으로 누운 스캔 사진을 90°씩 돌리기
- **자막**: *연도·라벨*(금색 큰 글씨, 예: 1998) + *설명*(예: 본사 이전 기념 단체사진)
- **카메라 움직임**: 자동 / 확대 / 축소 / ←→↑↓ 이동 / 고정
- **표시 시간**: 이 사진만 더 길게/짧게
- **다음 장면 전환**: 이 사진 다음에 나올 전환 효과

## 2단계 · 문구 (인트로·엔딩)
- **인트로 10종** — 카드에 실제 모습이 보입니다. 클릭하면 바로 미리보기 재생
  | 인트로 | 어울리는 영상 |
  |---|---|
  | **타임 롤** (NEW) | 창립·기념일 — 흑백 사진이 세로로 휘리릭 흐르며 연도가 올라가고(예: 1996→2026), 섬광과 함께 컬러로 바뀌며 타이틀. 연도는 문구 단계의 *연도 카운터 시작/끝*에서 바꾸거나 **사진 연도로 채우기**로 자동 입력 |
  | **플래시 컷** (NEW) | 행사·스포츠·연말 — 사진이 번쩍이며 빠르게 교차, 큰 글자가 꽂히는 강렬한 오프닝 |
  | 골든 타이틀 | 창립기념·시상식 |
  | 메모리 모자이크 | 연말결산·단체 행사 (내 사진들이 벽처럼 펼쳐짐) |
  | 이어온 시간 | 기념일 (1996→2026 연도 카운터) |
  | 시네마 오프닝 | 졸업·행사 (영화 같은 레터박스) |
  | 폴라로이드 | 여행·가족 (인화 사진이 떨어지며 쌓임) |
  | 플로럴 블룸 | 웨딩·생일 (꽃잎과 빛망울) |
  | 미니멀 라인 | 추모·기업 (절제된 모던 스타일) |
  | 필름 카운트다운 | 가족·레트로 (3·2·1 영사기) |
- **인트로 세부 조정** (인트로 카드 아래)
  - *글자 전에 사진만 보이는 시간*: 메모리 모자이크·폴라로이드·타임 롤 등 사진 인트로에서 배경 사진을 더 오래/짧게 (초 단위로 표시)
  - *글자가 나타나는 속도*: 천천히 / 보통 / 빠르게
  - *글자 뒤 사진 어둡기*: 사진을 더 밝게 보이게 하거나 글자를 더 또렷하게
  - 글자가 끝까지 읽히도록 필요하면 인트로 길이를 자동으로 늘리고, 몇 초가 되는지 알려 줍니다
  - **기본값으로** 버튼으로 언제든 되돌리기
- **타이틀 문구**: 큰 글자(30, 2026, 1 등) / 작은 영문 / 메인 타이틀 / 날짜 / 기관·이름 — 비워 둔 칸은 표시되지 않습니다
- **로고**: 투명 배경 PNG 권장. 인트로·엔딩·워터마크에 사용
- **엔딩 3종**: 갤러리 월(사진이 흐르는 벽) / 엔딩 크레딧(이름이 올라감) / 심플
  - 크레딧 입력 형식: `# 함께한 사람들`(제목), `기획 : 홍길동`(2단), 빈 줄(간격)

## 3단계 · 스타일
- **컬러 테마 7종**: 블랙&골드, 네이비&샴페인, 버건디&골드, 아이보리&브라운, 블러시&로즈골드, 세이지 그린, 스카이 블루
- **글꼴 7종**: 클래식 명조, 모던 고딕, 로열 클래식, 감성 바탕, 로맨틱 스크립트, 발랄한 둥근체, 손글씨 다이어리
- **전환 스타일 6종**: 우아하게 · 시네마틱 · 경쾌하게 · 로맨틱 · 신나게 · 레트로 필름 → *다시 섞기*로 조합 변경
- **전환 효과 21종 개별 지정**: 필름스트립 사진 사이의 **◆** 클릭 → 효과 클릭 → 그 부분이 바로 재생됩니다. *모든 장면 전환에 적용* 버튼으로 한 번에 통일 가능
- **카메라 움직임**: 없음 / 은은하게 / 보통 / 역동적
- **몽타주 장면**: 끄기 / 가끔(12~16장마다) / 보통(7~10장마다) / 자주(4~6장마다)
- **폴더 이름 표시**: 표시 안 함 / 폴더가 바뀔 때만 / 모든 사진 — 사진이 들어 있던 폴더 이름을 화면 왼쪽 위에 작게 표시 (예: `D:\사진\01_2019_체육대회` → *2019 체육대회*, 앞의 정렬용 번호는 자동 제거). 행사·연도별로 폴더를 나눠 두면 어떤 사진인지 바로 알 수 있습니다
- **자막 위치**: 왼쪽 아래 / 가운데 아래
- **워터마크**: 로고(없으면 기관명)를 사진 장면 구석에 상시 표시
- **사진 색감**: 자연스럽게 · 따뜻한 필름 · 빈티지 · 선명하게 · 흑백 + 비네팅 · 필름 그레인

## 4단계 · 음악

  - 모든 곡은 **CC0 퍼블릭 도메인**(FreePD.com) 음원이라 행사 상영·유튜브·SNS에 **출처 표기 없이** 쓸 수 있습니다
  - 곡마다 소리 크기를 맞춰 두었고, 영상보다 짧으면 자동으로 반복됩니다 (원하면 *영상 길이를 음악에 맞추기*)
  - 목록이 비어 있으면(설치 파일에 음악이 빠진 경우) **인터넷에서 무료 음악 목록 받기** → 곡을 누르면 내려받아 바로 들어 볼 수 있습니다

## 5단계 · 내보내기 (PC에 영상 파일로 저장)
1. **점검** 목록 확인 — 빨간 항목(파일 없음 등)이 있으면 클릭해서 해당 사진으로 이동
2. **화면 비율**: 가로 16:9(행사 스크린·유튜브) / 세로 9:16(쇼츠·릴스) / 정사각 1:1 / 세로 4:5(인스타 피드)
3. **화질**: Full HD 1080p 권장 (4K는 4K 스크린일 때만)
4. **영상 파일 만들기** → 저장 위치·파일 이름 선택 → 진행률 표시 → 완료 후 *폴더 열기 / 영상 재생*

### 제작 시간 줄이기
- **빠른 시안 먼저 만들기**: 720p·빠른 압축으로 먼저 만들어 오타·순서·음악을 실제 영상으로 확인한 뒤 최종본을 만드세요.
- **예상 제작 시간**은 한 번 만들고 나면 이 PC의 실제 속도로 계산해 보여줍니다.
- **인코딩 방식 ‘자동’**: 그래픽카드(NVIDIA·Intel·AMD) 가속이 가능하면 자동으로 사용하고, 문제가 있으면 CPU로 자동 전환합니다.
- 만드는 동안 창을 최소화하고 다른 일을 해도 됩니다. 작업 표시줄에 진행률이 보이고, 끝나면 알림이 뜹니다.
- 저장 위치의 공간이 부족하면 시작 전에 알려 줍니다.

### 편하게 쓰는 요령
- 각 단계 맨 아래 **‘다음: …’** 버튼을 따라가면 순서대로 완성됩니다.
- 제목·문구 입력칸을 누르면 미리보기가 그 글자가 나오는 장면으로 이동해, 입력하는 즉시 확인할 수 있습니다.
- 필름스트립은 **마우스 휠**로 좌우 이동, 오른쪽 위 **작게**를 누르면 한 화면에 더 많은 사진이 보입니다.
