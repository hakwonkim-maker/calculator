# MEMORIA 기념영상 스튜디오 — 사용 설명서

모든 기능은 **마우스 클릭**으로 적용됩니다. 무엇을 누르든 가운데 미리보기에 바로 반영되니 마음껏 눌러 보세요.
실수해도 **Ctrl+Z**(또는 상단 ↶ 버튼)로 되돌릴 수 있고, 작업은 자동 저장됩니다.

```
┌ 상단: 템플릿 · 열기 · 저장 · [영상 만들기] ─────────────────────────────┐
│ 단계 │ 설정 패널     │        미리보기 (재생·탐색)       │ 선택 항목 속성 │
│ 사진 │ (단계별 옵션) │                                   │ (자막·회전 등) │
│ 문구 │               │                                   │                │
│스타일│               ├───────────────────────────────────┴────────────────┤
│ 음악 │               │ 필름스트립: 인트로 ◆ 사진 ◆ 사진 ◆ … ◆ 엔딩         │
│내보내기               │ (드래그로 순서 변경, ◆ 클릭 = 전환 효과 선택)        │
└──────┴───────────────┴────────────────────────────────────────────────────┘
```

---

## 빠른 시작 (5분)
1. 프로그램을 켜면 **"어떤 영상을 만드시나요?"** 창이 뜹니다 → 원하는 종류를 클릭
   (창립·기념일 / 웨딩 / 생일·돌잔치 / 졸업·입학 / 여행 앨범 / 가족 앨범 / 추모·헌정 / 행사 하이라이트 / 연말 결산)
2. **사진 폴더 선택** → 사진이 촬영일 순서로 들어옵니다
3. 왼쪽 **문구** 단계에서 제목·날짜·이름을 내 내용으로 바꿉니다
4. **음악** 단계 → *음악 파일 추가* → *음악 길이에 영상 맞추기*
5. **내보내기** → *영상 파일 만들기* → 저장 위치 선택 → 완료되면 *영상 재생*

## 1단계 · 사진
| 기능 | 사용법 |
|---|---|
| 사진 불러오기 | **폴더 선택**(하위 폴더 포함 가능) 또는 **사진 선택**. 사진·폴더를 창에 끌어다 놓아도 됩니다 |
| 순서 정리 | **촬영일순 / 파일명순 / 역순 / 섞기** 버튼. 필름스트립에서 사진을 끌어 원하는 위치에 놓기 |
| 여러 장 선택 | Shift+클릭(범위), Ctrl+클릭(하나씩), Ctrl+A(전체) → 함께 끌어 옮기거나 삭제 |
| 연도별 챕터 자동 생성 | 촬영 연도가 바뀌는 곳마다 "1998" 같은 제목 카드를 자동 삽입 |
| 사진에 촬영 연도 표시 | 각 사진 자막에 촬영 연도를 자동 입력 |
| 챕터(텍스트) 카드 추가 | 사진 사이에 "1부 · 우리의 시작" 같은 제목 화면 넣기 |
| 사진 1장당 시간 | 슬라이더, 또는 **전체 길이 맞추기** 1분/2분/3분/5분/10분 클릭 |
| 화면 맞춤 | 자동(권장) / 꽉 채우기 / 전체 보이기(흐린 배경) |

## 사진 하나 다듬기 (오른쪽 속성 창)
필름스트립에서 사진을 클릭하면 오른쪽에 속성 창이 열립니다.
- **중심점**: 사진에서 꼭 보여야 할 곳(얼굴)을 클릭 → 화면을 꽉 채울 때 그 부분이 잘리지 않습니다
- **회전**: 옆으로 누운 스캔 사진을 90°씩 돌리기
- **자막**: *연도·라벨*(금색 큰 글씨, 예: 1998) + *설명*(예: 본사 이전 기념 단체사진)
- **카메라 움직임**: 자동 / 확대 / 축소 / ←→↑↓ 이동 / 고정
- **표시 시간**: 이 사진만 더 길게/짧게
- **다음 장면 전환**: 이 사진 다음에 나올 전환 효과

## 2단계 · 문구 (인트로·엔딩)
- **인트로 8종** — 카드에 실제 모습이 보입니다. 클릭하면 바로 미리보기 재생
  | 인트로 | 어울리는 영상 |
  |---|---|
  | 골든 타이틀 | 창립기념·시상식 |
  | 메모리 모자이크 | 연말결산·단체 행사 (내 사진들이 벽처럼 펼쳐짐) |
  | 이어온 시간 | 기념일 (1996→2026 연도 카운터) |
  | 시네마 오프닝 | 졸업·행사 (영화 같은 레터박스) |
  | 폴라로이드 | 여행·가족 (인화 사진이 떨어지며 쌓임) |
  | 플로럴 블룸 | 웨딩·생일 (꽃잎과 빛망울) |
  | 미니멀 라인 | 추모·기업 (절제된 모던 스타일) |
  | 필름 카운트다운 | 가족·레트로 (3·2·1 영사기) |
- **타이틀 문구**: 큰 글자(30, 2026, 1 등) / 작은 영문 / 메인 타이틀 / 날짜 / 기관·이름 — 비워 둔 칸은 표시되지 않습니다
- **로고**: 투명 배경 PNG 권장. 인트로·엔딩·워터마크에 사용
- **엔딩 3종**: 갤러리 월(사진이 흐르는 벽) / 엔딩 크레딧(이름이 올라감) / 심플
  - 크레딧 입력 형식: `# 함께한 사람들`(제목), `기획 : 홍길동`(2단), 빈 줄(간격)

## 3단계 · 스타일
- **컬러 테마 7종**: 블랙&골드, 네이비&샴페인, 버건디&골드, 아이보리&브라운, 블러시&로즈골드, 세이지 그린, 스카이 블루
- **글꼴 7종**: 클래식 명조, 모던 고딕, 로열 클래식, 감성 바탕, 로맨틱 스크립트, 발랄한 둥근체, 손글씨 다이어리
- **전환 스타일 6종**: 우아하게 · 시네마틱 · 경쾌하게 · 로맨틱 · 신나게 · 레트로 필름 → *다시 섞기*로 조합 변경
- **전환 효과 21종 개별 지정**: 필름스트립 사진 사이의 **◆** 클릭 → 효과 클릭 → 그 부분이 바로 재생됩니다. *모든 장면 전환에 적용* 버튼으로 한 번에 통일 가능
- **카메라 움직임**: 없음 / 은은하게 / 보통 / 역동적
- **자막 위치**: 왼쪽 아래 / 가운데 아래
- **워터마크**: 로고(없으면 기관명)를 사진 장면 구석에 상시 표시
- **사진 색감**: 자연스럽게 · 따뜻한 필름 · 빈티지 · 선명하게 · 흑백 + 비네팅 · 필름 그레인

## 4단계 · 음악
- **음악 파일 추가** (여러 곡 가능, ▲▼로 순서 변경) — 곡 사이는 자연스럽게 겹쳐 이어집니다
- **음악 길이에 영상 맞추기**: 음악이 끝나는 순간 영상도 끝나도록 사진 시간을 자동 계산
- 음악 반복, 음량, 시작 페이드인, 끝 페이드아웃, 크로스페이드 길이

## 5단계 · 내보내기 (PC에 영상 파일로 저장)
1. **점검** 목록 확인 — 빨간 항목(파일 없음 등)이 있으면 클릭해서 해당 사진으로 이동
2. **화면 비율**: 가로 16:9(행사 스크린·유튜브) / 세로 9:16(쇼츠·릴스) / 정사각 1:1 / 세로 4:5(인스타 피드)
3. **화질**: Full HD 1080p 권장 (4K는 4K 스크린일 때만)
4. **영상 파일 만들기** → 저장 위치·파일 이름 선택 → 진행률 표시 → 완료 후 *폴더 열기 / 영상 재생*

## 저장 · 불러오기
- **저장**(Ctrl+S): `.memoria` 프로젝트 파일 — 며칠에 걸쳐 작업할 때
- 프로그램이 갑자기 꺼져도 다음 실행 시 마지막 작업이 자동 복원됩니다
- 프로젝트 파일은 사진 원본 위치를 기억합니다. 사진 폴더를 옮기면 "파일 없음"으로 표시됩니다

## 단축키
`Space` 재생/정지 · `←/→` 이전/다음 장면 · `Delete` 삭제 · `Ctrl+Z` 되돌리기 · `Ctrl+Shift+Z` 다시 실행 · `Ctrl+S` 저장 · `Ctrl+A` 전체 선택 · `Esc` 선택 해제
