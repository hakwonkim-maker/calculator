# MEMORIA 기념영상 스튜디오 — PC 설치 가이드

## 0. 결론부터
**영상을 만드는 PC에는 추가로 설치할 프로그램이 없습니다.**
설치 파일(.exe) 하나에 영상 인코더(FFmpeg)와 모든 글꼴이 들어 있어서, 인터넷이 없는 곳에서도 동작합니다.

| 항목 | 권장 사양 |
|---|---|
| 운영체제 | Windows 10 / 11 (64비트) |
| 메모리 | 8GB 이상 (4K 출력은 16GB 권장) |
| 저장 공간 | 프로그램 약 500MB + 영상 파일 (1080p 5분 ≈ 300~600MB) |
| 그래픽 | 일반 내장 그래픽이면 충분. 그래픽 드라이버가 없는 PC도 동작하지만 영상 만드는 속도가 느려집니다 |

---

## 1. 설치 파일 받기

### 방법 A — GitHub에서 받기 (가장 쉬움)
1. GitHub 저장소 → 상단 **Actions** 탭 → 왼쪽 **MEMORIA Windows Installer** 클릭
2. 맨 위(가장 최근) 실행 기록 클릭 → 아래 **Artifacts**의 `MEMORIA-Film-Studio-Windows` 클릭
3. 내려받은 zip 압축을 풀면 `MEMORIA-Film-Studio-Setup-1.1.0.exe`가 나옵니다
   - Artifacts는 GitHub 로그인이 필요하고 90일 동안 보관됩니다.
   - 저장소에 `memoria-v1.1.0` 같은 태그를 올리면 **Releases** 페이지에도 자동 게시되어 로그인 없이 받을 수 있습니다.

### 방법 B — 내 PC에서 직접 만들기
필요한 프로그램 (둘 다 무료):

| 프로그램 | 용도 | 다운로드 |
|---|---|---|
| **Node.js 22 LTS** | 설치 파일 빌드 | https://nodejs.org/ko/download (Windows Installer .msi, 기본값으로 설치) |
| Git (선택) | 소스 내려받기 | https://git-scm.com/download/win — 또는 GitHub에서 **Code → Download ZIP** |

1. 소스를 내려받아 압축을 풉니다 (경로에 한글이 없어도, 있어도 됩니다).
2. `memory-film` 폴더의 **`build-installer.bat`** 를 더블클릭합니다.
3. 몇 분 뒤 `memory-film\release` 폴더가 열리고 설치 파일이 생깁니다.
   - 설치 없이 바로 실행해 보려면 **`run-app.bat`** 를 더블클릭하세요.

---

## 2. 설치하기
1. `MEMORIA-Film-Studio-Setup-1.1.0.exe` 더블클릭
2. **"Windows의 PC 보호"** 파란 창이 뜨면 → **추가 정보** → **실행**
   (회사 인증서로 서명하지 않은 프로그램이라 나오는 일반적인 안내입니다)
3. 설치 위치를 고르고 **설치** → 바탕화면에 **MEMORIA 기념영상 스튜디오** 아이콘이 생깁니다.

> 사내 PC에서 설치가 막히면 IT 담당자에게 "서명되지 않은 설치 프로그램 허용"을 요청하세요.

## 3. 삭제하기
Windows **설정 → 앱 → 설치된 앱 → MEMORIA Film Studio → 제거**
(작업한 프로젝트 파일 `.memoria`와 만든 영상은 지워지지 않습니다.)

## 4. 자주 묻는 질문
- **아이폰 사진(HEIC)이 안 들어가요** → 아이폰 *설정 → 카메라 → 포맷 → 높은 호환성*으로 바꾸거나, 사진을 PC로 옮길 때 JPG로 변환해 주세요. Windows *사진* 앱에서 "다른 이름으로 저장 → JPG"도 가능합니다.
- **음악은 어떤 형식?** MP3, M4A, WAV, OGG, FLAC
- **만든 영상은 어디서 재생되나요?** 표준 MP4(H.264)라서 Windows 미디어 플레이어, PowerPoint, 카카오톡, 유튜브, 인스타그램 모두 그대로 사용 가능합니다.
- **영상 만드는 시간은?** Full HD 5분 영상 기준 일반 사무용 PC에서 약 5~15분. 4K는 약 4배 걸립니다. 만드는 중 창을 최소화해도 됩니다.
